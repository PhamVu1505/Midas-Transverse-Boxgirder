2. CAI DAT
================================================================================

  - Khong can cai Python

================================================================================
3. CHUAN BI FILE DXF (MAT CAT NGANG)
================================================================================

3.1. Phan mem: AutoCAD (hoac tuong thich, luu dang .dxf)

3.2. Don vi: MET (meters) - tat ca kich thuoc tinh bang met

3.3. He toa do:
     - X: phuong ngang
     - Y = 0 tai mat tren ban mat cau
     - Y < 0 huong xuong duoi
     - Y = -H tai day ban day

3.4. Cac layer bat buoc:

     +----------+-------------+----------------------------------------------+
     | Layer    | Entity      | Mo ta                                        |
     +----------+-------------+----------------------------------------------+
     | OUTPOLY  | LWPOLYLINE  | 8 dinh = duong vien ngoai mat cat            |
     | INPOLY   | LWPOLYLINE  | 10 dinh = lo rong ben trong                  |
     | TEXT     | TEXT         | Ten mat cat (vd: "s16", "S1")                |
     +----------+-------------+----------------------------------------------+

     CHU Y: Chi dung LWPOLYLINE (polyline 2D), KHONG dung LINE, CIRCLE, SPLINE

3.5. OUTPOLY - 8 dinh (duong vien ngoai):

     V2(-8.17, 0) -------------------------------- V1(+8.17, 0)     <- mat tren
     V3(-8.17,-0.25)                          V8(+8.17,-0.25)       <- mep canh hang
              \                            /
               V4(-4.60,-0.65)  V7(+4.60,-0.65)                     <- web junction
                \              /
                 V5(-4.28,-H)--V6(+4.28,-H)                         <- day

     - V1, V2: mep tren (Y=0), xac dinh B_total
     - V3, V8: dau canh hang, xac dinh chieu day dau canh
     - V4, V7: vi tri giao web/ban tren
     - V5, V6: day mat cat, xac dinh H va B_box_bot

3.6. INPOLY - 10 dinh (lo rong ben trong):

          V6(-2.05,-0.30)------V7(+2.05,-0.30)     <- mat trong ban tren
         /                                      \
     V5(-4.05,-0.65)                  V8(+4.05,-0.65)  <- web inner top
        |                                        |
     V4(-4.05,-mid)                   V9(+4.05,-mid)   <- web inner mid
         \                                      /
       V3(-3.90,-(H-0.6))        V10(+3.90,-(H-0.6))  <- haunch day
            \                        /
          V2(-2.40,-(H-0.3))--V1(+2.40,-(H-0.3))      <- mat trong ban day

     - V1, V2: mat trong ban day -> chieu day ban day
     - V3, V10: haunch day
     - V4,V5 va V8,V9: mat trong bung -> chieu day bung
     - V6, V7: mat trong ban tren -> chieu day ban tren

3.7. Dat ten file: S0.dxf, S1.dxf, ..., S16.dxf, SLT.dxf

================================================================================
5. TAO FILE MCT (GENERATE)
================================================================================

5.1. Mo ung dung
5.2. Tab "Generate":
     - [Files...] hoac [Folder...] : chon file DXF
     - [Browse...] Excel data      : chon file Excel tai trong
     - [Browse...] Output dir       : chon thu muc xuat (mac dinh: output/)
     - [Generate All]               : tao MCT + SVG

5.3. Ket qua:
     output/
       S16/
         S16_frame.mct    <- File MCT, import vao Midas
         S16_frame.svg    <- Hinh SVG de kiem tra

================================================================================
6. CHAY MIDAS/CIVIL
================================================================================

6.1. Mo Midas/Civil
6.2. File > Import > chon file .mct
6.3. Kiem tra mo hinh:
     - Nodes/Elements dung vi tri
     - Section shapes hien thi dung
     - Tai trong dung huong va cuong do
6.4. Analysis > Perform Analysis
6.5. Export ket qua:
     - Results > Forces > Beam Forces
     - Export dang .xls
     - Dat ten: "Beam Force_S16.xls" (hoac tuong tu)
     - Luu vao thu muc output/S16/

================================================================================
7. DOC KET QUA (RESULTS)
================================================================================

7.1. Tab "Results":
     - [Browse...] Excel data   : chon file Excel (cung file o buoc 5)
     - [Browse...] Output folder : chon thu muc output
     - [Scan]                    : tim cac section co Beam Force XLS
     - [Process All]             : doc ket qua, tinh check points

7.2. Bang kiem tra 8 diem A-H:
     - A-D: Ban tren (top slab)
     - E-F: Ban day (bottom slab)
     - G-H: Bung (web)
     - Gia tri: Mu (kN.m), Vu (kN), Mser (kN.m), h (mm)

7.3. Ket qua luu tai:
     output/S16/S16_check.txt    <- Bang text
     output/S16/S16_check.xlsx   <- File Excel bao cao
